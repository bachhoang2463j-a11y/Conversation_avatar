# 情绪头像 EmotionAvatar

SillyTavern 酒馆助手（TavernHelper / JS-Slash-Runner）轻量脚本：AI 在角色对话的自然段前输出 `{角色名(情绪)}` 标签，脚本在**显示层**把标签替换为头像，并以**两列布局**呈现——头像占左列、整段文字占右列，左缘整齐无绕排。

设计原则（与"对话气泡"类插件相反）：

- **不修改消息原文**——`chat[i].mes` 永不触碰，只改渲染后的 DOM；停用脚本即回到原始文本
- **不强制任何输出格式**——不禁写法、不限单行台词、正文完整走酒馆原生 markdown 渲染
- **逐标签独立替换**——漏一个标签只少一个头像，段落文本永不受损，无"整段渲染失败"
- **两列布局纯 CSS 实现**——段首头像段落加 `eca-p` 走 flex 两列（头像左列、文字右列），`:has()` 兜底无 `p` 包裹的容器；标签行自动拆成独立段落再两列化——双列只含标签所在的那一行，其后的换行内容独立成段、不进右列，仅行内文字中的标签保持行内样式；无头像段落不受影响
- 零轮询、零 `setInterval`、事件驱动 + 按变更楼层合并的流式渲染；流式输出期间实时渲染——生成期在 DOM 变更回调内**同帧**完成替换（酒馆每个 token 重写楼层时，头像被抹掉与补插落在同一帧，看不到原始标签闪现），非生成期按 250ms 窗口合并；只扫变更楼层、已渲染头像就地更新，不整段重建；开启延时渲染后改为生成期间不替换、完成后统一处理

## 安装

1. 前提：酒馆已安装 **酒馆助手（JS-Slash-Runner）** 扩展
2. 酒馆助手 → 脚本库 → 导入 `emotion-avatar.js`（或新建全局脚本，粘贴文件全文）
3. 刷新酒馆页面，顶部魔法棒菜单出现「情绪头像」入口
4. **只保留一份脚本**：同一个页面如果加载了两份情绪头像（旧版本没删干净、或重复导入成两个脚本），启动时会弹提示条并在控制台告警。两份脚本会同时抢头像的点击与语音状态，表现为「点一下直接出声、不进入加载态」「长按重新生成像没反应」等错乱——请到脚本库删掉旧版本后刷新页面

## 快速上手

1. 魔法棒菜单 → **情绪头像**
2. 面板底栏 **＋ 新增角色** / **＋ 新增分组**：输入角色名（须与 AI 输出的角色名逐字一致），可创建手风琴分组管理不同会话/卡片的角色
3. 为角色配置头像，三种方式：
   - **单格上传**：点击对应情绪的格子，选一张图片（自动降采样到长边 ≤256px）
   - **多选导入**：在任意格子处打开文件选择框后**一次选中多张**，按文件名自动匹配情绪——文件名里包含哪个情绪词（如 `弗兰克-微笑(2).png`、`惊讶.jpg`）就归入哪个格子；文件名形如 `角色名-情绪.png` 的图片可直接落地**新自定义情绪**，其余不含情绪词的跳过并提示
   - **批量导入大图**：上传一张表情合集大图（2×5、3×3 等均匀网格），自动猜测行列、每格映射一个情绪词（下拉含「✎ 自定义…」可录入新情绪），一次导入多张
4. **自定义情绪**：网格末尾「＋ 新增情绪」格可为**该角色**追加固定十情绪之外的情绪（输入名称后立即选图）；自定义格悬停可见 ✕，删除即移除该情绪与图片。有图才算该情绪存在，各角色互不影响
5. **多姓名绑定**：详情头「多姓名」按钮可为该角色绑定其它姓名（逗号分隔），AI 输出任一姓名都显示同一套头像；提示词仍只罗列主名
6. 之后每次生成，AI 会按注入的提示词在对应自然段前输出 `{角色名(情绪)}`，界面自动显示头像。
7. 如果流式输出时头像频闪，打开面板底栏的**延时渲染**开关：生成期间保留原始标记，收到消息完成/停止事件后统一替换；宿主未提供完成事件时会在静默约 1 秒后兜底替换。关闭开关即恢复流式期间的实时替换。

## 标签格式

```
{角色名(情绪)}
```

- 固定情绪词十个：**默认、微笑、愤怒、悲伤、惊讶、轻蔑、杀意、思考、大笑、害羞**；另可按角色新增自定义情绪（见上文「自定义情绪」）
- 角色名可用「多姓名」绑定的任一姓名，均渲染同一套头像
- 渲染容错：
  - 已登记角色 + 有效情绪 → 对应头像
  - 已登记角色 + 该角色没有的情绪词（含其他角色的自定义情绪）/ 缺图 → 自动回落该角色「默认」头像
  - 未登记角色 → 灰色问号占位头像（悬停可看名字，便于发现漏登记）
  - 标签行自动拆段：无论标签前是空行还是单换行（showdown `simpleLineBreaks` 会把它留在同段落中部），双列单元都只含**标签所在的那一行**；同段落内标签行之后的换行内容自动排除出右列、独立成段（如紧随标签行的 `测试测试测试测试`）；同一行内的长台词完整保留在右列；仅行内文字中的标签（前面无换行）不拆段。拆段处的 `<br>` 会被删除（由段边界替代换行），段落之间只有正常段间距、不产生空白行
- 流式渲染：默认实时且不闪标签——生成期（`GENERATION_STARTED` → 完成事件）内的 DOM 变更在同一帧内完成替换，非生成期按 250ms 窗口合并，只处理发生变更的楼层，已渲染头像就地更新不重建；开启延时渲染后改为生成期间保留原始标记，`MESSAGE_RECEIVED` / `GENERATION_ENDED` / `GENERATION_STOPPED` 后统一替换，宿主未提供完成事件时静默约 1 秒兜底。
- 头像素材覆盖或删除时，已渲染楼层会就地更新为新图/占位，不需要等待楼层重渲染。

## 提示词注入

- 通道：酒馆助手 `injectPrompts`，**system 角色 / in_chat / 深度 0**（上下文最末尾，紧贴最新消息）
- 内容：`<头像标记>` XML 包裹短规范 + 登记名单 + 情绪词表 + 示例（示例角色名取第一个登记角色）
- 情绪词表动态生成：固定十个 + 启用组各角色**实际已传图**的自定义情绪；某角色缺少某情绪时提示词会注明回落「默认」
- 注入只对当前聊天有效：切换聊天、修改登记名单时自动重注；面板总开关关闭即撤销；停用脚本自动撤销
- 标签保留在上下文中（约 10 token/段）——这是特性：AI 看到自己历史输出里的标签，格式一致性更强

## 头像语音

点击**真实头像**（非占位）本身即可朗读：只读**该头像自己那一段**引号内的对白，不跨段、不读旁白、不调用任何 LLM。

- **提取规则**：只认完整闭合的双引号对（`“…”`、`"…"`、`「…」`、`『…』`、`«…»`）；单引号 `‘…’` 只作为外层引号内的嵌套标点。同一段里被旁白打断的多句对白按原文顺序合并为**一次**合成请求，旁白文本不发送。无完整引号的段落不可点。
- **楼层范围**：仅 AI 楼层；用户楼层即使手写标签也不显示语音（无点击态）。同一段出现两个头像时（如 `{A(微笑)}“甲。”{B(愤怒)}“乙。”`），两个头像各读自己的台词。
- **播放与队列**：点击开始合成（暖金微光呼吸）→ 出声（金漪涟漪）→ 再点停止。**点另一个头像不会打断当前播放**：新的一段立刻进入加载态开始合成，就绪后排在队尾，等前一段播完自动接播——合成是并行的，出声是串行的，同一时刻只有一段在响。点正在播放的头像 = 停止并立刻接播下一条；点已排队的头像 = 只取消那一条，不影响正在播的。队列最多 5 条，超出会提示并拒绝入队。**取消是真的取消**：会立即中断在途请求，被取消的合成不会再冒出来播放，也不会弹出迟到的失败提示。只有用户点击才发起请求，不自动播放、不监听新消息。
- **清缓存重新生成**：**长按头像**（触摸设备长按；PC 上按住鼠标左键不动，约 0.6 秒；**右键头像**同样可以直接呼出），位移容差鼠标 24px / 触摸 12px（按住时手抖不会被误判成拖动）——**无确认弹窗、不需要该段已有缓存**，直接强制重新生成这一段：绕过内存与磁盘两层缓存重新请求，成功后新音频原地覆盖同一条缓存记录（不新增条目），失败则旧缓存原样保留、因此不提示确认也没有风险。过程中提示「正在强制重新生成这一段…」，拿到结果后再提示「已重新生成（本次未使用缓存）」，便于确认这一次确实是新合成而不是回放。正在播别的段时**不会被打断**：重生成完排到队尾等播（提示里会多一句「已加入播放队列」），重生成的就是正在播的那一段时原地替换、立刻重播；重生成沿用这一条当前用的那套音色（第二音色在播时不会被悄悄换回第一音色）。长按后松手带出的那一次点击不会误触发播放，也不会把正在进行的重新生成当成「再点停止」打断；触摸拖动超过容差则让位给滚动、不触发。已有缓存的段落也可在面板底栏「语音缓存」里试听、下载、单条删除。
- **传输通道**：合成请求走 `XMLHttpRequest` 而不是 `fetch`。原因是酒馆里多个插件会包装 `window.fetch` 做全局响应缓存（如 st-immersive-sound 的 `tts-persistent-cache` 按 host+path 判引擎并直接返回它自己的缓存 Response），走 fetch 会被就地替换成第三方缓存——既发不出真实请求，「重新生成」永远拿不到新音频，而它的缓存键还会抹掉情绪等字段、可能串音。XHR 不经过 fetch，绕开这类补丁。
- **角色音色**：在面板选中角色 → 「语音设置」里为该角色选择引擎与音色（别名自动继承主角色的配置）。未配置音色的角色点头像会提示先去配置。
- **第二音色（双击）**：「语音设置」里除第一音色外还能再配一套**第二音色**（默认「无」）。配好后**双击头像**即改用第二音色朗读——第一音色繁忙、或多次生成都不满意时的快速切换；单击仍走第一音色。没配第二音色的角色双击不做任何额外动作（与加此功能前一致）。第一音色始终必填，第二音色随时可以选回「无」关闭。用过第二音色后会自动**清掉这一段第一音色的旧缓存**（内存与持久化两层，只清这一段、不动第二音色自己的缓存），免得之后单击又放出那版被淘汰的音频；代价是那次单击会重新请求一次第一音色。
- **引擎与情绪**（情绪取自 `{角色(情绪)}` 标签，均不读进正文）：
  - **Edge**（免费，默认引擎）：情绪映射到该音色支持的 `style`；无法表达的（如自定义情绪）回落到 `general`。文本经第三方公开代理合成；「音频设置」里代理**留空**即由脚本自动探活择优、失败自动轮换，**填入地址**则固定只用该地址。语速/音调在「语音设置」里**按角色**单独保存（% 与 Hz，初始值取「音频设置」里的全局默认）。
  - **MiniMax**：固定情绪映射到官方枚举（微笑→happy、愤怒→angry、悲伤→sad、惊讶→surprised、轻蔑→disgusted、思考→calm、大笑→happy、杀意→angry）；无法映射的情绪不发送情绪参数，由模型按文本自然处理。
  - **豆包**：情绪（含自定义情绪）作为独立语音指令放在 `additions.context_texts`，例如「请用“杀意”的语气朗读这段话。」——支持任意中文情绪词，且不会朗读指令本身。音色是**内置下拉**（大壹、知性灿灿、儒雅逸辰、魅力女友、儿童绘本、vivi 等 16 个官方音色，另有「✎ 自定义…」可手填 speaker id）；**Resource ID 也已内置**（语音合成 2.0 `seed-tts-2.0` / 声音复刻 2.0 `seed-icl-2.0`），用户无需手输，老配置里留空会自动回落到语音合成 2.0。
  - **MiMo（小米）**：走 OpenAI 风格 `POST /chat/completions`（鉴权头 `api-key` + `Authorization`），音频以 base64 放在 `choices[0].message.audio`；情绪作为独立 user 指令（与豆包同一条通道，支持任意中文情绪词）。音色可选 9 个预置，也可上传参考音频做**音色复刻**（可添加多个、各自独立，参考音频存 IndexedDB；选用复刻音色时自动切到 `mimo-v2.5-tts-voiceclone`）。`voicedesign` 文字描述音色未支持。
  - 失败后会对**同一引擎自动重试一次**（间隔 500ms），仍失败才提示可重试；凭据未配置、内容过滤、代理全部不可用、HTTP 4xx 等确定性错误不重试。始终不自动切换引擎或音色。
- **持久化缓存**：Edge 默认不落盘（仅当前页面内存缓存）；MiniMax / 豆包 / MiMo 默认落盘到 IndexedDB，同引擎+同音色+同文本+同情绪再次播放直接回放，不再消耗合成额度。面板底栏「语音缓存」可查看条目、试听、下载、单条删除、清理过期与清空全部。默认保留 30 天 / 最多 200 条 / 最多 512MB，超出按最旧优先清理。
- **持久化开关**：四个「持久化」开关**勾选即生效并立即写盘**，不必点「保存」（弹窗的 ×／遮罩／取消也不会把开关改动回滚）。关掉后该引擎不再写入也不再命中缓存，但**已存在的缓存不会被自动删除**——它们仍列在「语音缓存」里并标注「已停用」，需要时手动清即可。
- **开关**：面板底栏「语音」总开关（默认开），关闭后头像不再可点、状态类全部清掉、**播放队列立即全停**，音色配置与缓存不受影响。

## 数据存储

| 数据 | 位置 | 说明 |
|---|---|---|
| 头像图片（含自定义情绪图） | 浏览器 IndexedDB `EmotionAvatarDB` | 主键 `角色名_情绪`，全局角色库（不绑角色卡，换卡/群聊通用） |
| 登记名单、分组、开关、尺寸、裁剪比例 | localStorage `emoavatar_groups` / `emoavatar_characters` / `emoavatar_settings` | |
| 多姓名绑定（别名表） | localStorage `emoavatar_aliases` | 主名 → 其它姓名列表 |
| 角色语音映射（第一音色 + 第二音色，各含引擎 / 音色 / Resource ID / 语速 / 音调） | localStorage `emoavatar_tts_voices` | 按主名保存，别名自动继承；改名随迁、删除角色即清除；第二音色缺省即「无」 |
| 语音引擎凭据与缓存策略 | localStorage `emoavatar_tts_config` | Edge 代理、MiniMax Key/平台/模型、豆包 App ID/Access Key、MiMo API Key/Base URL/模型/格式、持久化开关与容量上限。**凭据为该脚本私有，不读取其他插件**，以明文存于浏览器，同源脚本理论上可读 |
| 持久化语音音频 | 浏览器 IndexedDB `EmotionAvatarTtsDB` | 按「引擎+平台/模型/Resource ID+音色+正文+最终情绪参数+语速/音调/音量」为键；Edge 默认不写入 |
| MiMo 复刻参考音频 | 浏览器 IndexedDB `EmotionAvatarTtsDB` 的 `clones` 仓 | 与语音缓存分开存放，**清空语音缓存不会删掉复刻音色**；localStorage 里只留昵称/格式/大小等元数据 |

头像显示大小：面板底部滑条（1.5–5em），即时生效，已渲染楼层无需重扫。

段首头像默认与整段文字**垂直居中**；面板底栏「＋ 新增分组」右侧依次有「延时渲染」和「置顶」开关。延时渲染用于流式频闪兜底，置顶勾选切为顶端首行平齐，状态持久化。窄屏（≤640px）下面板自动纵向堆叠、情绪网格降为 3 列、底栏收紧，情绪名省略不竖排。

## 已知限制

- **TTS 会朗读标签原文**（酒馆 TTS 读消息原文，插件无法拦截；本脚本自己的语音只读引号内对白，不含标签）
- 语音的**情绪变化精度按引擎递减**：豆包可表达任意中文情绪，MiniMax 只能落到固定枚举，Edge 只能映射到音色支持的 style（无对应项即 `general`）——Edge 是降级引擎，不是等价实现
- **MiniMax / 豆包 / MiMo 为浏览器直连**：受服务商 CORS 策略与网络环境影响，被拦截时界面提示请求失败（不会偷偷改走代理或换引擎）。MiMo 的 `api.xiaomimimo.com` 已实测放行跨域，未填 Key 时会返回 401 而不是被浏览器拦截
- **Edge 走第三方公开代理**：点击头像会把该段对白文本发送到代理服务。脚本内置代理池，留空时自动选延迟最低的可用代理并在失败时切下一个（「音频设置」→「检测代理」可查看当前可用列表），也可填入自己的服务地址固定使用。代理均为第三方服务，可用性不由本脚本保证；HTTPS 页面下 HTTP 代理会被浏览器拦截，此时只剩 HTTPS 代理可用
- 凭据以明文存放在浏览器 localStorage，同源脚本可读取；请勿在共享环境中使用
- 播放/排队状态在楼层重渲染后会自动恢复（按角色+文本匹配，并重新绑定到新头像元素上），但**同一句对白在同一楼层多个头像上出现时**只算一条：仅保留一个状态，播放队列里也只占一个位置
- 配了第二音色的头像，**双击判定窗口（350ms）内的第二次点击不再当作「再点停止」**，而是交给双击去切第二音色；要停止请稍慢地再点一次。未配第二音色的头像没有这层判定
- 播放队列上限 5 条：点得太快超出后会提示并拒绝入队，等前面播完再点
- 长按清缓存按「当前引擎 + 音色 + 文本 + 情绪 + 语速音调」精确匹配那一条记录：改过音色或参数后，旧键下的缓存成为孤儿，长按找不到它，需要到「语音缓存」面板手动删除
- 图片库在浏览器 IndexedDB：清浏览器数据 / 换浏览器会丢（暂无导出导入，可后续加）
- 批量导入仅支持**均匀网格**的合集图；带间距、不等分、斜排的图请退回单格上传
- 单花括号与酒馆宏（`{{}}`）、markdown 无冲突；开启 LaTeX 渲染的极端环境理论上可能干扰
- 删除脚本后，顶栏按钮与样式元素会残留到下次刷新页面为止（无害）

## 卸载与清理
